# 💰Personal Expense Tracker
C++ Console Application | CS0053 Final Group Project 
Main Project File

## 📋I. INTRUCTIONS
- **Project Title:** Personal Expense Tracker Using C++ 
- **Project Type:** Console-Based Application 
- **Primary Algorithm:** Rule-Based Budgeting Algorithm 

##  📝II. PROJECT DESCRIPTION
Develop a console-based Personal Expense Tracker that allows users to record, organize, search, update, 
and delete expenses. The system calculates budget allocations using the 50/30/20 rule, monitors 
spending, and displays summaries of expenses and remaining balances.
